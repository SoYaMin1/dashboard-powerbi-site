Источник данных

AdventureWorksDW2022

AdventureWorksDW2022 — учебное хранилище данных от Microsoft для SQL Server. Оно описывает вымышленную компанию Adventure Works Cycles, которая производит и продаёт велосипеды, комплектующие, одежду и аксессуары.

Хранилище построено по схеме «звезда»: таблицы фактов с продажами связаны с измерениями дат, продуктов, клиентов и географии. Эта структура хорошо подходит для построения моделей и отчётов в Power BI.
